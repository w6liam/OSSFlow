# noType brand

noType is open source voice dictation. You bring your own AI keys. There is no account, nothing is stored in the cloud, and you own your data.

The mark is the OpenMoji studio microphone, U+1F399. It is the file `logo/mark.svg`, used as published. Do not redraw it.

Studio microphone by [OpenMoji](https://openmoji.org). The emoji is licensed CC BY-SA 4.0. That license covers the microphone artwork. It does not relicense the rest of noType. https://creativecommons.org/licenses/by-sa/4.0/

## Mark

Clear space around the mark is one quarter of the emoji tile. Do not put type or another symbol inside that space.

| File | Use |
| --- | --- |
| `logo/mark.svg` | The microphone, unchanged. Use on ink and on paper. |
| `logo/mark-mono.svg` | OpenMoji outline of the same microphone. Status bar and themed icons only. |
| `logo/wordmark.svg` | Microphone plus the word noType in paper. Use on ink. |
| `logo/wordmark-ink.svg` | Microphone plus the word noType in ink. Use on paper. |
| `logo/app-icon.svg` | Ink tile, signal ring, microphone. App icon and avatar. |
| `logo/png/mark-512.png` | Microphone, 512 px, transparent ground. |
| `logo/png/mark-1024.png` | Microphone, 1024 px, transparent ground. |
| `logo/png/wordmark-512.png` | Paper wordmark, 512 px tall, transparent ground. |
| `logo/png/wordmark-1024.png` | Paper wordmark, 1024 px tall, transparent ground. |
| `logo/png/app-icon-192.png` | App icon at 192 px. |

The word “noType” is one word. The T is capital. Outfit SemiBold, set tight. Do not set the name in another typeface.

Say “voice dictation” when you mean the product. “Transcription” is the API setting, not the name of the app.

## Color

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#07080D` | Dark ground, idle bubble, app icon |
| Surface | `#141821` | Raised panels on ink |
| Hairline | `#2A3142` | Dividers on ink |
| Signal | `#2EE6C7` | The listening color on ink. Rings, selected controls. |
| Signal deep | `#0F766E` | The listening color on paper |
| Paper | `#F4F1EA` | Light ground, and text on ink |
| Ink text | `#12141C` | Text on paper |

Record is `#E11D48`. Success is `#15803D`. Delete and errors use the same red. Those are states, not brand colors. Do not recolor the microphone.

## Type

Outfit, SIL Open Font License. The file and the license are in `fonts/`. Screen titles and the wordmark use Outfit SemiBold. Long text, such as a transcript, stays in the system font.

## Light and dark

Dark is the primary face: the microphone and paper type on ink, signal for the live state. Light is paper with ink text, the same microphone, and signal deep for the live state.

## Do not

- Stretch the microphone, or add a shadow to it.
- Use a second accent color.
- Compare noType with another product in the mark, the wordmark, or this folder.
