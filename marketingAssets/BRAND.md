# noType brand

noType is open source voice dictation. You bring your own AI keys. There is no account, nothing is stored in the cloud, and you own your data.

The mark is a capsule microphone. Use the Signal fill on ink. Use the outline for the status bar, themed icons, and paper. Do not redraw the paths in `logo/mark.svg` and `logo/mark-mono.svg`.

## Mark

Clear space around the mark is one quarter of the tile. Do not put type or another symbol inside that space.

| File | Use |
| --- | --- |
| `logo/mark.svg` | Signal capsule. Use on ink. |
| `logo/mark-mono.svg` | Outline of the same microphone. Status bar and themed icons. |

| `logo/png/wordmark-512.png` | Paper wordmark, 512 px tall, transparent ground. |
| `logo/png/wordmark-1024.png` | Paper wordmark, 1024 px tall, transparent ground. |
| `logo/png/app-icon-192.png` | App icon at 192 px. |

The word “noType” is one word. The T is capital. Outfit SemiBold, set tight. Do not set the name in another typeface.

Say “voice dictation” when you mean the product. “Transcription” is the API setting, not the name of the app.

## Listening

The signal ring is the listening indicator. It pulses while recording. The idle mark is still. Record stays `#E11D48`. Success stays `#15803D`.

## Color

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#07080D` | Dark ground, idle bubble, app icon |
| Surface | `#141821` | Raised panels on ink |
| Hairline | `#2A3142` | Dividers on ink |
| Signal | `#2EE6C7` | The listening color on ink. Rings, selected controls. |
| Signal deep | `#0F766E` | The listening color on paper |
| Paper | `#F4F1EA` | Light ground, and text on ink |
| Ink text | `#12141C` | Text on paper |

Record is `#E11D48`. Success is `#15803D`. Delete and errors use the same red. Those are states, not brand colors. Do not recolor the microphone beyond the signal fill and the mono outline.

## Type

Outfit, SIL Open Font License. The file and the license are in `fonts/`. Screen titles and the wordmark use Outfit SemiBold. Long text, such as a transcript, stays in the system font.

## Light and dark

Dark is the primary face: the capsule and paper type on ink, signal for the live state. Light is paper with ink text, the outline capsule, and signal deep for the live state.

## Do not

- Stretch the microphone, or add a shadow to it.
- Use a second accent color.
- Compare noType with another product in the mark, the wordmark, or this folder.
