# Security

OSSFlow has no account system and no project server. API keys, recordings, and transcripts stay on the phone, apart from the HTTPS calls you configure to your transcription and cleanup hosts.

## Reporting a vulnerability

Report a vulnerability through GitHub Security Advisories:

https://github.com/w6liam/OSSFlow/security/advisories/new

Please give the project time to read the report before any public write-up. A public issue is a poor place for an unfixed vulnerability.

In scope: this Android app, including how it stores API keys, handles the microphone recording, and uses Accessibility to insert text. The transcription or cleanup provider you choose is outside this project.
